## 1. Опис проєкту

Проєкт демонструє роботу планувальника операційної системи реального часу FreeRTOS на емуляторі під ОС Windows. Реалізовано три незалежні періодичні задачі, що конкурують за час центрального процесора згідно з пріоритетною моделлю витіснення.

### Розрахункові параметри (Варіант 18)
* **Префікс задач:** `SEYA_` (перші дві літери прізвища та імені)
* **Формули:**
  * $T_1 = 13 + (18 \pmod 7) = 17\text{ ms}$
  * $T_2 = 21 + (18 \pmod 5) = 24\text{ ms}$
  * $T_3 = 34 + (18 \pmod 9) = 34\text{ ms}$
  * $C_1 = 2 + (18 \pmod 3) = 2\text{ ms}$
  * $C_2 = 3 + ((18 / 3) \pmod 3) = 3\text{ ms}$
  * $C_3 = 4 + ((18 / 5) \pmod 3) = 4\text{ ms}$
  * Пріоритети: $18 \pmod 2 = 0 \implies \tau_1 > \tau_2 > \tau_3$

| Задача | Системне ім'я | Період ($T_i$, мс) | Тривалість обчислень ($C_i$, мс) | Пріоритет у FreeRTOS |
| :--- | :--- | :--- | :--- | :--- |
| $\tau_1$ | `SEYA_T1` | 17 | 2 | 3 (Найвищий) |
| $\tau_2$ | `SEYA_T2` | 24 | 3 | 2 (Середній) |
| $\tau_3$ | `SEYA_T3` | 34 | 4 | 1 (Низький) |

## 2. Структура коду

* `main.c` — перемикання режиму роботи через `#define mainCREATE_SIMPLE_BLINKY_DEMO_ONLY 1`.
* `main_blinky.c` — реалізація:
  * функції штучного навантаження CPU `simulate_busy_work()`;
  * функцій періодичних задач `prvSEYA_Task1`, `prvSEYA_Task2`, `prvSEYA_Task3`;
  * ініціалізація диспетчера у `main_blinky()`.

## 3. Інструкція із запуску проєкту

### Вимоги:
* Visual Studio 2022 (з компонентом Desktop development with C++)
* FreeRTOS Kernel (демо-оточення WIN32-MSVC)

### Покроковий запуск:
1. Завантажити ядро FreeRTOS або відкрити налаштований проєкт симулятора:
   ```cmd
   git clone [https://github.com/FreeRTOS/FreeRTOS.git](https://github.com/FreeRTOS/FreeRTOS.git)
   cd FreeRTOS
   git submodule update --init --recursive
   ```
2. Помістити файли `main.c` та `main_blinky.c` у директорію `FreeRTOS/Demo/WIN32-MSVC/`.
3. Відкрити файл рішення `FreeRTOS/Demo/WIN32-MSVC/WIN32.sln` у Visual Studio.
4. Зібрати та запустити проєкт комбінацією клавіш `Ctrl + F5` або `F5`.
5. У консолі спостерігати логування початку та завершення виконання задач за системними тіками.
